# Create Skills

Плагин для DeepSeek Harness: страница **Skills** в боковой панели, каталог скиллов по категориям, создание и правка, бюджет промпта и A/B-сравнение версий скилла.

> Статус: **P0 — проектирование**. Плагин ещё не установлен; код появится на этапе P1.

## Что это

Скилл в DSH — папка с `SKILL.md` в одном из корней (`.dsh/skills` проекта, `~/.dsh/skills`, `.agents/skills`). Реестр подхватывает её на лету. Сейчас установка — ручное копирование, каталога и UI нет, а каждый установленный скилл навсегда занимает место в системном промпте.

Create Skills делает скиллы управляемым активом:

- **Страница Skills** — установленные скиллы, источник, категория, вес в токенах, включён/выключен.
- **Каталог** — готовые скиллы по категориям с описаниями; установка одного, нескольких или всех, с подтверждением и прогнозом бюджета.
- **Редактор** — создание и правка имени, описания, «когда применять», тела.
- **Оптимизация** — предупреждение о разросшемся каталоге и выключение скилла через `disable-model-invocation` без удаления.
- **A/B** — две панели с разными версиями скилла и своими чатами, сравнение результатов и оценка.

## Структура

```

  README.md

    architecture.md        — компоненты и потоки данных
    skill-format.md        — формат SKILL.md и правила валидации
    catalog.md             — формат каталога и установка
    decisions.md           — принятые решения (ADR)
  catalog/
    catalog.json           — 10 тестовых скиллов
    sources.md             — источники и лицензии
  package.json             — манифест плагина (заполняется в P1)
```
