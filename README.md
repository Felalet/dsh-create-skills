# Create Skills

Плагин для **DeepSeek Harness**: страница скиллов в боковой панели — каталог с предпросмотром, редактор, версии, корзина и A/B-сравнение с ИИ-улучшением.

[English version](README.en.md) · MIT · DSH 0.2.x · Windows / macOS / Linux

## Возможности

- **Установленные** — скиллы проекта и пользовательские: источник, категория, вес в промпте, включён/отключён. Отключённые здесь скрыты, их видно и включают в каталоге.
- **Каталог** — готовые скиллы по категориям. Клик по строке открывает предпросмотр `SKILL.md` до установки. Установка одного или всех сразу, в проект или в пользовательские, с выбором конкретной рабочей области.
- **Редактор** — имя, описание, «когда применять», тело в Markdown; шаблон с подсказками и полем инструкций на 42vh; правка категории и удаление в архив.
- **Версии** — сохранить текущее состояние, применить версию, удалить одну или «оставить только последнюю».
- **Сравнение A/B** — две стороны из установленных скиллов **или из каталога без установки**; ИИ-оценка, построчный diff, поле «Что улучшить» для целевого изменения; применённая версия переезжает в левую часть для следующей итерации.
- **Архив** — удаление переносит скилл в корзину: восстановление в исходный корень, удаление навсегда, очистка; записи сгруппированы по категориям.
- **Рабочие области** — список скиллов других областей, «Открыть», «Скопировать сюда» и «Собрать со всех». При совпадении имени — сравнение и выбор: оставить своё или заменить (старое уходит в архив).
- **Контекстное меню сессии** — правый клик по чату → **Skills**: страница открывается на рабочей области этого чата.
- **Локализация** — русский, английский, упрощённый китайский; каталог двуязычный (ru/en).
- **Кроссплатформенность** — чистый Node.js в хосте, без shell и платформенных API.

## Требования

- DeepSeek Harness **0.2.x** (проверено на 0.2.1-rc.5)
- Node.js ≥ 22.19 (идёт в комплекте с DSH)
- Для установки из каталога — доступ в интернет (скачивание с GitHub)

## Установка

Из GitHub-репозитория:

```bash
dsh plugin --profile desktop add github:<owner>/dsh-create-skills
```

Из локального архива:

```bash
npm pack
dsh plugin --profile desktop add ./create-skills-0.1.0.tgz
```

После установки **перезапустите DSH** и откройте **Skills** в боковой панели.

## Быстрый старт

1. **Каталог** → клик по строке — читаете описание и `SKILL.md`.
2. **Установить** — выберите область: «в проект» (только эта рабочая область) или «в пользовательские» (все проекты). В «в проект» можно указать конкретную рабочую область.
3. **Установленные** — включение/отключение и вес в промпте; «Править» открывает редактор, «Версии» — историю.
4. **Сравнение** — выберите скилл слева, напишите «Что улучшить» и нажмите «Улучшить скилл»: результат появится справа и сразу сравнится.
5. **Архив** — всё удалённое лежит здесь, пока не очистите.

## Где живут скиллы

| Область | Путь |
|---|---|
| Проект | `<рабочая область>/.dsh/skills/<имя>/SKILL.md` |
| Проект (совместимый корень) | `<рабочая область>/.agents/skills/...` |
| Пользователь | `~/.dsh/skills/...` |
| Пользователь (совместимый корень) | `~/.agents/skills/...` |

DSH определяет корень проекта как ближайшую папку с `.git`; если её нет — берётся сама рабочая область.

Данные плагина:

- версии — `<проект>/.dsh/skill-versions/<скилл>/<метка>/SKILL.md`;
- архив — `~/.dsh/skill-archive/<id>/` (с `meta.json`: имя, категория, исходный путь, дата);
- пользовательские категории — `<проект>/.dsh/skill-categories.json`;
- «Недавние» пути — `localStorage` браузера (только пути, без данных).

## Формат SKILL.md

```markdown
---
name: my-skill
description: "Что делает скилл и когда его применять — до 200 символов в одну строку"
whenToUse: "Необязательное уточнение триггера"
metadata:
  category: "development"
---

# Заголовок

## Когда применять
## Шаги
## Проверка
```

`name` — kebab-case, `description` обязателен. `disable-model-invocation: true` скрывает скилл от модели, `user-invocable: false` — из меню `/`. Плагин пишет категорию в `metadata.category`.

## Разработка

```bash
node scripts/validate-catalog.mjs   # структура каталога
node scripts/check-client.mjs       # загрузка клиента, словари ru/en/zh, отсутствие жёстких строк
node scripts/test-archive.mjs       # архив: перенос, список, восстановление, удаление, очистка
node scripts/test-preview.mjs       # предпросмотр из GitHub (нужна сеть)
node icons/build-icons.mjs          # пересобрать SVG-иконки
```

Структура:

```
client.js            # браузерная часть: страница, диалоги, локализация
index.js             # хост: JSON API /plugins/create-skills/api/*
cordis.patch.yml     # подключение плагина в профиль
catalog/catalog.json # 10 скиллов из anthropics/skills
locale/{ru,en,zh}.json
icons/               # исходники иконок и превью
scripts/             # проверки и служебные скрипты
docs/                # архитектура, формат скилла, каталог, решения
```

## Ограничения

- Встроенные скиллы DSH (`skill-office`: `office*`, а также `diagnose-windows-sandbox-acl`) принадлежат поставке приложения — их нельзя удалить или отключить по одному. Отключается только весь провайдер `skill-office` на странице «Плагины».
- Сравнение работает в пределах текущей рабочей области (установленные и каталожные скиллы); сравнение «область против области» пока не поддерживается.
- Плагин выполняет файловые операции в корнях скиллов и скачивает `SKILL.md` с GitHub. Сторонние скиллы — это инструкции для агента: ставьте только те, которым доверяете.
