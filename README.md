# Create Skills

Плагин для DeepSeek Harness: страница **Skills** в боковой панели, каталог скиллов по категориям, создание и правка, бюджет промпта и A/B-сравнение версий скилла.

> Статус: **P1 — каркас установлен**. В профиле `desktop` активен бандл
> `create-skills`: страница Skills в сайдбаре со списком скиллов проекта,
> источником и весом в промпте. Каталог, редактор и A/B — следующие этапы.

## Что это

Скилл в DSH — папка с `SKILL.md` в одном из корней (`.dsh/skills` проекта, `~/.dsh/skills`, `.agents/skills`). Реестр подхватывает её на лету. Сейчас установка — ручное копирование, каталога и UI нет, а каждый установленный скилл навсегда занимает место в системном промпте.

Create Skills делает скиллы управляемым активом:

- **Страница Skills** — установленные скиллы, источник, категория, вес в токенах, включён/выключен.
- **Каталог** — готовые скиллы по категориям с описаниями; предпросмотр `SKILL.md` по клику на строку; установка одного, нескольких или всех, с подтверждением и прогнозом бюджета.
- **Редактор** — создание и правка имени, описания, «когда применять», тела.
- **Оптимизация** — предупреждение о разросшемся каталоге и выключение скилла через `disable-model-invocation` без удаления.
- **A/B** — две панели с разными версиями скилла и своими чатами, сравнение результатов и оценка.

## Локализация

Интерфейс переключается вместе с языком приложения (**Настройки → Общие → Язык**): плагин регистрирует три словаря — русский, английский и упрощённый китайский (`zh`). Китайский входит в DSH из коробки, отдельный языковой пакет ставить не нужно.

- Тексты страницы, кнопок, диалогов и шаблон нового скилла берутся из словаря активного языка (108 ключей в каждом, наборы совпадают).
- Язык ответов ИИ (подбор категории, группировка, сравнение версий) передаётся в хост и совпадает с активным языком.
- Метаданные плагина в менеджере плагинов локализованы через `locale/{ru,en,zh}.json`.
- Данные каталога (`catalog/catalog.json`) двуязычные: русские `title`/`description` для `ru`, английские `titleEn`/`descriptionEn` — для всех остальных языков, включая китайский.

## Кроссплатформенность

Плагин рассчитан на Windows, macOS и Linux: хост-часть — обычный Node.js на `node:fs`/`node:path`, без shell, реестра и платформенных API; клиентская часть — веб-бандл, одинаковый во всех сборках DSH. Требуется DSH 0.2.x и Node.js ≥ 22.19 (входит в поставку DSH).

Установка в профиль (подставьте свой профиль вместо `desktop`):

```bash
# из папки плагина — собрать архив и установить
npm pack
dsh plugin --profile desktop add ./create-skills-0.1.0.tgz

# или сразу из git-репозитория
dsh plugin --profile desktop add github:<owner>/create-skills
```

`private: true` в `package.json` запрещает публикацию в npm-реестр, но не мешает `npm pack` и установке из git.

Что учтено специально для POSIX:

- при установке скилла из каталога сохраняются симлинки внутри бандла (только ведущие внутрь скилла) и бит выполнения у файлов;
- проверка «путь внутри разрешённого корня» идёт через `path.relative`, поэтому корень файловой системы, `..` и регистр в путях не дают ложных отказов;
- `$DSH_AGENTS_HOME/skills` (по умолчанию `~/.agents/skills`) входит в разрешённые корни наравне с `~/.dsh/skills`.

## Структура

```
create-skills/
  README.md
  PLAN.md                  — план работ, оценки, вопросы
  docs/
    architecture.md        — компоненты и потоки данных
    skill-format.md        — формат SKILL.md и правила валидации
    catalog.md             — формат каталога и установка
    decisions.md           — принятые решения (ADR)
  catalog/
    catalog.json           — 10 тестовых скиллов
    sources.md             — источники и лицензии
  package.json             — манифест плагина (dsh.bundle + dsh.client)
  index.js                 — host: JSON API /plugins/create-skills/api/skills
  client.js                — web: страница Skills и иконка в сайдбаре
  cordis.patch.yml         — вставка строки плагина
  icon.svg                 — иконка панели
  locale/ru.json, en.json, zh.json  — meta.title / meta.description для Plugin Manager
```
